# Manuel Gouveia Cunga | Portfólio

Analista de Teste e Desenvolvedor Front-end. React 19, Vite, Tailwind CSS 4.

## Executar
```
npm install --legacy-peer-deps
npm run dev
```

## Antes de publicar
1. Coloque a nova foto em `public/profile.jpg` (recomendado 640x800, abaixo de 200 KB).
2. Em `.env` configure as chaves do EmailJS (veja `.env.example`). Não envie o `.env` para o GitHub.
3. Registe o site no Google Search Console, cole o código de verificação em `index.html` e submeta `/sitemap.xml`.
4. Se mudar o domínio, actualize o URL em `index.html`, `public/robots.txt` e `public/sitemap.xml`.

Os conteúdos (PT/EN) estão em `src/lib/data/portfolio-data.ts`.
